Карта · из чего состоит Claude

Шесть инструментов, которые стоит знать

Чат умеет все. Остальные пять превращают его из собеседника в сотрудника, который сам работает с вашими файлами, сервисами и кодом. Нажмите на плитку, чтобы перейти к разделу.

Шаг 0 · подготовка

С чего начать

  1. Зарегистрируйтесь на claude.ai

    Чат и проекты есть даже на бесплатном тарифе.

  2. Установите приложение для компьютера

    Mac или Windows: claude.ai/download. Cowork и Claude Code лучше всего работают именно в приложении.

  3. Выберите тариф под задачи

    Cowork и Claude Code доступны на платных тарифах: Pro, Max, Team, Enterprise. Актуальные цены смотрите на сайте Claude.

  4. Запустите мастер настройки

    В новом диалоге напишите /setup-claude: выберете роль, плагин и подключите сервисы.

Совет: заполните Settings → Profile, кто вы и чем занимаетесь. Claude будет учитывать это в каждом ответе.

Cowork · что это

Cowork: Claude работает, пока вы заняты другим

В обычном чате вы получаете ответ текстом. В Cowork вы описываете результат, а Claude сам разбивает задачу на шаги, читает файлы, ходит в подключенные сервисы и отдает готовую работу: таблицу, документ, презентацию, разобранную папку.

  • Видно ход работы. Справа появляется список шагов с галочками.
  • Работа с вашими папками. Claude читает и сохраняет файлы только там, куда вы дали доступ.
  • Задачи по расписанию. Команда /schedule запускает задачу каждый день или по требованию.
  • Задачи с телефона. Можно поставить задачу из мобильного приложения и вернуться к готовому результату.
Чем отличается от чата: чат отвечает, Cowork делает.

Cowork · как включить

Как перейти в режим Cowork

  1. Откройте приложение Claude на компьютере

    Войдите в аккаунт с платным тарифом.

  2. Найдите переключатель под полем ввода

    Рядом с + есть переключатель Chat / Cowork. Выберите Cowork.

  3. Выберите, где работать

    Через + добавьте папку на компьютере или файлы. Можно работать и внутри проекта.

  4. Опишите результат, а не шаги

    «Сделай таблицу…», «Разбери…», «Подготовь отчет…». И отправьте.

Безопасность: давайте доступ к конкретной рабочей папке, а не ко всему диску. Claude спросит разрешение перед важными действиями.

Порядок в файлах

Разобрать папку «Загрузки»

Сотни файлов разложены по папкам: документы, договоры, фото, счета. Названия приведены в единый вид, дубли собраны отдельно.

Промпт
Разбери папку «Загрузки»: разложи файлы по папкам «Документы», «Договоры», «Счета», «Фото», «Видео», «Прочее». Переименуй в формате ГГГГ-ММ-ДД_название. Дубли сложи в папку «Дубли», ничего не удаляй. В конце дай короткий отчет, что куда переместил.
Таблицы

Excel из чеков и счетов

Claude читает PDF и фото, вытаскивает суммы и даты и собирает таблицу с работающими формулами и итогами по месяцам.

Промпт
В папке «Чеки» лежат PDF и фото. Собери Excel: дата, поставщик, сумма, категория. Добавь лист с итогами по месяцам и категориям через формулы и диаграмму. Если что-то не распознал, отметь строку желтым.
По расписанию

Утренняя сводка каждый день

С подключенными почтой и календарем Claude каждое утро собирает, что важно сегодня. Настраивается командой /schedule.

Промпт
/schedule Каждый будний день в 8:30: просмотри почту за последние сутки и мой календарь на сегодня. Сделай сводку: 3 главных дела, письма, на которые нужно ответить, и встречи с подготовкой к ним.

Проекты · зачем нужны

Проекты: отдельная «комната» под каждую задачу

Проект хранит инструкции, файлы и историю диалогов по одной теме. Не нужно каждый раз заново объяснять, кто вы, какой у вас продукт и как писать.

  • Инструкции — правила, которые Claude применяет во всех чатах проекта.
  • Файлы (Knowledge) — прайс, презентация, регламенты, примеры текстов.
  • Своя память — проект помнит только свое и не смешивается с другими чатами.
  1. В меню слева нажмите Projects → New project, задайте название и описание.
  2. Справа заполните Instructions и загрузите файлы.
  3. Начинайте чаты внутри проекта. Старый чат можно перенести в проект через меню у названия.

Проекты есть на всех тарифах; на бесплатном можно создать до 5 проектов. Идеи: «Мой бизнес», «Контент для соцсетей», «Продажи и КП», «Учеба».

Шаблон инструкции для проекта
Ты — мой помощник по [тема]. Обо мне: [кто вы, чем занимаетесь, клиенты]. Тон: [деловой / дружелюбный]. Всегда: [правила]. Никогда: [запреты]. Если данных не хватает, сначала задай уточняющие вопросы.

Коннекторы · доступ к сервисам

Коннекторы: Claude видит вашу почту, диск и календарь

Коннектор — это безопасное подключение Claude к сервису. Без него Claude знает только то, что вы вставили в чат. С ним он сам находит письмо, файл на диске или встречу в календаре.

  • Веб-коннекторы: Gmail, Google Drive, Календарь, Notion, Canva, Slack, Asana и десятки других.
  • Расширения для компьютера: доступ к локальным приложениям и файлам.
  1. В поле ввода нажмите + / Search and tools → Add connectors. Или откройте каталог claude.ai/directory.
  2. Выберите сервис и нажмите Connect, затем войдите в аккаунт сервиса.
  3. Проверьте: «Что у меня в календаре на завтра?»
Проверьте связку коннекторов
Найди в почте последние письма от [клиент], посмотри в Google Drive наше КП для него и предложи в календаре 2 свободных слота на созвон на этой неделе. Подготовь черновик ответа.

Скиллы · навыки по вашим правилам

Скиллы: научите Claude делать задачу «как у вас принято»

Скилл — это папка с инструкцией (файл SKILL.md) и, при необходимости, шаблонами и скриптами. Claude сам подключает нужный скилл, когда задача подходит под его описание.

  • Встроенные: Excel, Word, PowerPoint, PDF — работают автоматически.
  • Свои: «КП в фирменном стиле», «Пост в моем стиле», «Разбор договора по чек-листу».
  1. Включите выполнение кода: Settings → Capabilities → Code execution.
  2. В меню слева откройте Customize → Skills и включите нужные. В поле ввода скиллы вызываются через /.
  3. Свой скилл: + → Create skill. Можно создать в диалоге с Claude или загрузить ZIP-архив с папкой скилла.
Устанавливайте скиллы только из надежных источников и просматривайте их содержимое перед включением.
Создать свой скилл через диалог
Помоги создать скилл «Коммерческое предложение в моем стиле». Структура КП: [блоки]. Тон: [описание]. Вот 2 примера моих удачных КП: [вставьте]. Задай вопросы, если чего-то не хватает, и упакуй всё в скилл.

Плагины · всё в одном

Плагины: готовый набор под профессию

Плагин объединяет несколько скиллов, коннекторов и помощников. Например, плагин для маркетолога сразу умеет писать контент-план, анализировать конкурентов и работать с нужными сервисами.

  • Ставится один раз и работает в чате, Cowork и Claude Code.
  • Проще всего начать через /setup-claude: мастер сам предложит плагин под вашу роль.
  • Плагин можно настроить под свою компанию или собрать свой.
Порядок: сначала коннекторы и 1–2 скилла, потом плагин. Так вы поймете, что именно он делает.

Claude Code · что это

Claude Code: программист, которому достаточно объяснить словами

Агент, который работает с кодом в папке вашего проекта: читает файлы, пишет и правит код, запускает команды и проверяет результат. Не только для программистов: так делают сайты, Telegram-боты, парсеры и автоматизации.

Как он работает

  1. Изучает — читает файлы проекта, разбирается в структуре.
  2. Планирует — предлагает план изменений.
  3. Делает — пишет код и запускает команды.
  4. Проверяет — запускает тесты, исправляет ошибки и повторяет цикл.

Где работает: в приложении Claude (значок </> вверху слева), в терминале, в браузере на claude.ai/code, в VS Code и JetBrains. Нужен тариф Pro, Max, Team или Enterprise.

Claude Code · установка и первые команды

Запускаем Claude Code за 5 минут

Без терминала: нажмите значок </> вверху слева в приложении Claude или откройте claude.ai/code. В терминале:

1 · Установка — macOS / Linux
curl -fsSL https://claude.ai/install.sh | bash
1 · Установка — Windows PowerShell
irm https://claude.ai/install.ps1 | iex
2 · Запуск в папке проекта
cd ~/projects/my-site claude

При первом запуске откроется браузер для входа в аккаунт Claude. Проверить установку: claude --version.

КомандаЧто делает

/helpВсе команды
/resumeВернуться к прошлому диалогу
/clearНачать с чистого листа
Shift+TabПереключить режим разрешений

Привычка · как ставить задачу

Формула хорошей задачи для Claude

Claude работает как сильный новый сотрудник: чем понятнее поставлена задача, тем лучше результат.

  1. Контекст — кто вы и для чего задача.
  2. Цель — какой результат нужен.
  3. Материалы — файлы, ссылки, примеры.
  4. Формат — Excel, документ, пост, объем.
  5. Критерии — что точно должно быть и чего не должно.
Проверяйте цифры и факты в важных документах: Claude может ошибаться, особенно в расчетах и свежих данных.
Шаблон
Я [кто вы]. Мне нужно [цель], чтобы [зачем]. Используй [файлы / папку / данные из почты]. Результат: [формат, объем, структура]. Обязательно: [требования]. Не делай: [ограничения]. Если чего-то не хватает, сначала задай вопросы.
Пример
Я владелец кофейни. Мне нужен контент-план на ноябрь для Instagram, чтобы привлечь гостей в будни утром. Используй файл «Меню.pdf». Результат: таблица на 30 дней — дата, формат (рилс / пост / сторис), идея, текст. Обязательно 8 рилсов. Не используй шаблонные фразы.
